## Done

- Compared claude-obsidian's handling of sync, mobile and undo (read its README, `docs/compound-vault-guide.md`, `docs/install-guide.md`, `skills/wiki/references/operation-transactions.md`):
  - It doesn't use git for undo; git is opt-in checkpoints only.
  - Each write is a transaction journaled in `.vault-meta/` inside the vault, with crash recovery (`transaction recover`) but no undo of finished operations.
  - It says nothing about cloud sync or phones, and runs only locally, so it has the same "only the computer running Claude Code writes" constraint as Akasha.
- Added `akashactl recover` to the Phase 1 roadmap and to the next steps in `docs/context.md`.

## Learned

- Akasha's gap compared with claude-obsidian is interrupted writes. A power loss mid-apply leaves some pages written but uncommitted, plus a stale `.akasha/lock`. Nothing is lost (git has the previous versions), but cleanup is manual.

## Decisions

- No ADR: git-based undo (ADR-0003) stays. `recover` adds crash cleanup on top of it and doesn't change the design.
