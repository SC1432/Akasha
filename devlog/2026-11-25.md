# 2026-11-24 to 2026-11-25

**Phase:** 0 · Idea and design
**Time spent:** two planning sessions

## Done

- Defined the problem: Instagram posts and other resources get saved and never revisited, because saving is one tap and retrieval takes effort.
- First plan: Instagram share sheet → Telegram bot → fetch, transcribe, summarize → Obsidian note, with a weekly digest for resurfacing.
- Expanded scope to YouTube, web pages, books, PDFs and personal notes; split raw sources from distilled notes.
- Studied [claude-obsidian](https://github.com/AgriciDaniel/claude-obsidian): inbox → hash-named `.raw/` → `wiki/`, index/log/hot cache, source and claim ledgers, transactional single writer, read-only helper agents.
- Reviewed a "main agent + one subagent per life area" design and rejected it (see ADR-0002).
- Wrote the design doc and roadmap (`docs/design.md`, `docs/roadmap.md`).
- Created this repo (working name `brain`).
- Named the project **Akasha** after three rounds of candidates (Hippo, Muninn, Mimir, Memex, Loci and others). Chosen for being short, distinctive, and matching the idea of a complete record of what I learn; `/akasha:` is the command prefix and `akashactl.py` the writer.

## Learned

- claude-obsidian handles organizing and querying, not capture: PDFs/EPUBs get no text extraction, and web/YouTube need a separate runner. Capture is its own problem.
- Claude Code plugins are a directory with `.claude-plugin/plugin.json` plus skills, agents, hooks and MCP servers; `claude --plugin-dir` loads one without a marketplace.
- Every auto-invocable skill's name and description sits in context on every turn, so descriptions must stay short.
- Cloud sessions do not load local plugins; vault work happens locally.

## Decisions

- [ADR-0001](../docs/decisions/0001-claude-code-plugin.md): build as a Claude Code plugin with scheduled headless jobs, not a standalone Agent SDK app.
- [ADR-0002](../docs/decisions/0002-one-agent-skills-per-area.md): one main agent with skills per area; subagents only by task shape.
- [ADR-0003](../docs/decisions/0003-own-core-git-undo.md): write our own small core with a single writer and git-based undo instead of forking claude-obsidian.
